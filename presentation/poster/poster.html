01The problem

Large language models hallucinate: they give fluent, confident answers that are factually wrong, in exactly the same tone as correct ones. Detection must work without the right answer and without external fact-checking.

02Background: INSIDE & EigenScore

INSIDE measures how much several sampled answers disagree in meaning, using the model’s hidden states instead of its output words.

EigenScore = (1/K) · log det(Σ + αI) = (1/K) Σi log λi

Consistent answers → eigenvalues collapse → low score. Diverse answers → large eigenvalues → high score. Test-time feature clipping additionally truncates extreme activations in the penultimate layer (0.2% / 99.8% percentiles, memory bank of 3,000 tokens) to expose over-confident errors.

04Reproduction results

Llama-2-7B (4-bit), CoQA, 250 questions, K = 10 · AUROC, correct if ROUGE-L > 0.5 · ■ paper  ■ ours

The paper’s ranking reproduces exactly. EigenScore beats the strongest baseline by +2.9 AUROC (95% CI [−0.6, +6.5], paired bootstrap). The feature-clipping gain is inconclusive at this scale: −1.0, CI [−4.7, +2.6], against the paper’s +1.1.

05Limitations we identified

  • One hand-picked layer. EigenScore reads only layer L/2, yet the paper’s own ablation shows AUROC varies by several points across layers. The best layer is model-specific.
  • Scale-dominated covariance. A few very large (“massive”) activation dimensions can dominate the covariance instead of semantic differences.
  • Blind to consistent errors. When the model repeats the same wrong answer, all samples agree and the score trusts it; clipping helps only marginally.

06Proposed method: Multi-Layer EigenScore

1
Multi-layer aggregation. Average EigenScore over a fixed band of middle layers (L/4 to 3L/4; layers 8–24 of 32). This removes the hand-picked layer and averages out per-layer noise, like averaging several thermometers.
2
Scale normalisation. L2-normalise each answer embedding (or standardise each dimension using a memory bank) before the covariance, so the score reflects differences in meaning, not activation magnitude.
3
Confidence-aware hybrid. Rank-average Multi-Layer EigenScore with token-level confidence (LN-Entropy). When all answers agree, token confidence still signals uncertainty, targeting consistent hallucinations.
ML-ES = meanl ∈ [L/4, 3L/4] EigenScorel

All variants are training-free and computed from the same K samples: no extra generation, only more layers read.

08Conclusion

We restored a working implementation of INSIDE, completed its missing feature-clipping component, and reproduced its central finding on consumer hardware: internal-state consistency (EigenScore) is the strongest hallucination signal among the methods compared. Our extension targets its main weaknesses, the single-layer choice and the blind spot for consistent errors, with a training-free Multi-Layer EigenScore and a confidence-aware hybrid.
