1.Problem Statement

Large Language Models often hallucinate: they give confident answers that are wrong, in the same tone as correct ones.

Goal: for every answer, output a hallucination score that says how likely it is to be wrong, without knowing the correct answer, on an 8 GB laptop GPU.

2.The Idea: Ask Again, Check Agreement

We compare the answers not by their words but by the model’s internal representation of each answer: a list of numbers read from inside the network.

3.Intuition: Spread = Eigenvalues

EigenScore = average of log10(eigenvalues)
Answers agree → small eigenvalues → low score · disagree → large eigenvalues → high score

5.Illustrative Example (K = 3, d = 4)

Case A: answers agree

Z = [1.0 0.2 0.6 0.4] ← answer 1
    [1.1 0.2 0.6 0.4] ← answer 2
    [1.0 0.3 0.6 0.4] ← answer 3
C = cov(Z), 3×3 matrix
eigenvalues of C + 0.001·I:
0.362, 0.0017, 0.0011
score = mean(log10) = −2.05 → trust

Case B: answers disagree

Z = [1.0 0.2 0.6 0.4] ← answer 1
    [0.1 0.9 0.3 0.7] ← answer 2
    [0.5 0.4 1.0 0.0] ← answer 3
C = cov(Z), 3×3 matrix
eigenvalues of C + 0.001·I:
0.306, 0.114, 0.0022
score = mean(log10) = −1.37 → flag

When responses agree, one eigenvalue dominates and the rest collapse to ≈ 0.001, giving a low score. The computation is identical to the full-scale system.

7.Which Layer We Read, and Why

Layer 16 (middle): we read the vector of the last token of each answer: 4,096 numbers.

Why the middle? Early layers encode surface word patterns; the final layers focus on predicting the next word. The middle layers carry the most meaning.

Why the last token? The model reads left to right, so the last token has “seen” the whole answer.

Layer 31: where feature clipping caps each of its 4,096 neurons to its normal range (0.2–99.8 percentile of the last 3,000 tokens).

11.Conclusion & Limitations

Using only the model’s internal states (layer 16, 10 answers), our system flags likely-wrong answers with an 83.5% detection score, needs no answer key, and runs on an 8 GB laptop GPU.

  • Cost: each question needs 10 generated answers.
  • Access: needs the model’s internal layers, so it works with open models (not closed chat APIs).
  • Scope: it flags likely errors but does not correct them; tested on 250 CoQA questions.
